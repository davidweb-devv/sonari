Sonari ✦

Music that understands you.

Sonari is an independent music streaming application focused on music discovery, personalised recommendations, and a clean listening experience.

Tech Stack

- React + Vite
- JavaScript
- CSS
- Zustand
- Supabase

Status

Currently in active development.

Getting Started

git clone https://github.com/davidweb-devv/sonari.git
cd sonari
npm install
npm run dev
